### ✨ 新功能

- 新增 Anthropic 格式（/v1/messages）支持，配置页可切换 OpenAI / Anthropic 两种 API 格式
- 配置页新增「测试模型」按钮，保存前可用一道样例题验证模型连通性与回答格式
- 内置智谱、DeepSeek、阿里百炼三个 Anthropic 兼容预设；OpenAI 格式预设同步更新
- API URL 自动补全：OpenAI 格式自动补 `/chat/completions`，Anthropic 格式自动补 `/v1/messages`，无需填写完整端点

### 🐛 修复

- 紧凑化配置页布局（按钮横排），适配小终端窗口
- 兼容旧版配置文件，缺少 API 格式字段时自动回退到 OpenAI 兼容模式
- Anthropic 客户端检查响应 content-type，非流式响应时显式报错而非返回空内容
- 修正 fork 仓库的下载链接与自更新地址
